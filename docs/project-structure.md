## Project structure

```
carbonio-files-go-client/
├── config.example.yaml          # Configuration template (copied to config.yaml, which is gitignored, on first run)
├── cmd/
│   └── carbonio-files-go-client/
│       ├── main.go              # Entry point: dispatches to GUI (default) or CLI (-cli)
│       ├── app.go               # Wails-bound GUI backend (login, credential test/save, sync-folder wizard, sync orchestration/notifications, logging prefs)
│       ├── app_test.go          # GUI login/persist/auto-login/logout/sync-folder/credential-test/sync tests
│       ├── wails.json           # Wails project config
│       ├── rsrc_windows_amd64.syso  # Windows .exe icon resource (generated by img/regenerate-windows-icon.sh)
│       └── frontend/            # Svelte + Tailwind GUI (Vite build); src/ is source, dist/ is the embedded build output
│           └── src/
│               ├── components/  # Svelte views/panels (login, dashboard, sync/logging preferences, Docs Online viewer, shared ui/ widgets)
│               └── lib/         # api.js (Wails bindings wrapper), auth.js, i18n.js, stores.js, theme.js
├── pkg/
│   ├── actions/
│   │   ├── actions.go           # Business logic behind every CLI flag: upload/download/move/trash/delete, LiveCacheSync/FullCacheSync/UpdateCacheSync, SyncSummary
│   │   ├── actions_test.go
│   │   ├── deletemode_test.go
│   │   └── updatecachesync_test.go
│   ├── appdir/
│   │   └── appdir.go            # Resolves the per-user app directory for logs and SQLite databases
│   ├── carbonio/
│   │   ├── carbonio.go          # HTTP auth (classified AuthError) and file transfer
│   │   ├── session.go           # ZM_AUTH_TOKEN lifecycle: encrypted-at-rest reuse + transparent re-authentication
│   │   ├── docsproxy.go         # Local HTTP reverse proxy embedding Carbonio Docs Online in the GUI webview
│   │   └── *_test.go
│   ├── config/
│   │   ├── config.go            # config.yaml schema + loading
│   │   └── config_test.go
│   ├── graphql/
│   │   ├── graphqlClient.go     # GraphQL client wrapper
│   │   ├── graphqlAPI.go        # High-level API operations
│   │   ├── getChildren.go       # GetChildren query
│   │   ├── createFolder.go      # CreateFolder mutation
│   │   ├── moveNodes.go         # MoveNodes mutation
│   │   ├── deleteNodes.go       # DeleteNodes mutation
│   │   ├── trashNodes.go        # TrashNodes mutation
│   │   └── *_test.go
│   ├── i18n/
│   │   ├── i18n.go              # Locale resolution + catalog loading
│   │   ├── locale_linux.go      # OS locale detection (build-tagged per platform)
│   │   ├── locale_darwin.go
│   │   ├── locale_windows.go
│   │   └── locales/             # en.json, it.json translation catalogs
│   ├── localfs/
│   │   └── localfilesystem.go   # Local file system operations
│   ├── logger/
│   │   └── logger.go            # Process-wide zerolog logger, configured from Config
│   ├── notify/
│   │   └── notify.go            # Native desktop notifications (wraps gen2brain/beeep)
│   ├── sqlite/
│   │   ├── sqlitecache.go       # SQLite sync cache (per-file sync_status bookkeeping)
│   │   ├── sqliteconfig.go      # Encrypted-at-rest configuration table (CRUD)
│   │   ├── sqlitesyncmeta.go    # Last sync run outcome + pending-changes count
│   │   └── *_test.go
│   └── utils/
│       └── utils.go             # Shared helpers (e.g. RecursiveListNodeItems, timestamp conversion)
├── img/
│   ├── icon.go                  # Embeds ico.png/icon.ico as the tray/window/taskbar icon
│   ├── ico.png
│   ├── icon.ico
│   └── regenerate-windows-icon.sh
├── docs/                        # This documentation set (see README)
├── .github/workflows/build.yml  # CI build
├── Makefile
├── go.mod
└── go.sum
```
